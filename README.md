# insurance-claims-analysis
Insurance claims analysis using PostgreSQL, SQL, and Google Data Studio
## Business Question

What factors are associated with higher-cost insurance claims and longer claim resolution times?
## Project Overview

Analyzed insurance claims data to identify factors associated with claim severity and resolution time. The project includes data validation and cleaning in PostgreSQL, geographic enrichment using ZIP code data, SQL analysis, and an interactive dashboard.

## Data

- [Minitab Insurance Fraud Dataset](https://support.minitab.com/en-us/datasets/getting-started-guide-data-sets/insurance-fraud-data/)
- [U.S. ZIP Code reference table](https://simplemaps.com/data/us-zips)

## Tools

- PostgreSQL
- SQL
- DBeaver
- Google Data Studio
- GitHub

## Key Findings

- The analysis did not identify one dominant individual characteristic associated with higher claim severity.
- Substantial variation in claim amounts suggests that combinations of characteristics may be worth investigating further.
- Resolution times were generally consistent across the factors analyzed, with claim channel emerging as an area for further investigation.
